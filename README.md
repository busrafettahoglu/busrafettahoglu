# Busra Fettahoglu

High school student researcher and builder interested in Electrical and Computer Engineering, Edge AI, embedded systems, and human-centered technology. I like building systems that connect hardware, software, and AI, then testing how they behave outside a controlled demo.

## Current Focus

- Local AI that stays useful on small, resource-constrained hardware
- Speech and voice interaction in noisy, real-world conditions
- Accessible, human-centered computing

## Featured Work

### [Edge AI Voice Research](https://github.com/busrafettahoglu/edge-ai-voice-research)

An experimental platform for studying robust, speaker-aware voice interaction on resource-constrained edge hardware. The system runs locally on an NVIDIA Jetson Orin Nano and is being used to investigate speech reliability, acoustic conditions, latency, and compute tradeoffs.

Jetson Orin Nano · Python · Linux · Vosk · Silero VAD · whisper.cpp · Local LLMs · Piper

Ongoing research.

### [SeeAble](https://github.com/busrafettahoglu/seeable)

An accessibility-focused mobile application that helps blind and low-vision users understand visual scenes and hear printed text through spoken interaction.

React Native · Expo · TypeScript · Computer Vision · Mobile Accessibility

[Available on the App Store](https://apps.apple.com/app/id6794635818).

### [Dear Me: Then & Now](https://github.com/busrafettahoglu/dear_me_then_and_now)

A live digital time-capsule platform for writing letters to a younger self, future self, or the person someone is becoming, with consent, moderation, public publishing, and book-preparation workflows.

React · TanStack · TypeScript · Express · PostgreSQL · Docker · AWS · CloudFormation

[dearmethenandnow.com](https://dearmethenandnow.com/)
